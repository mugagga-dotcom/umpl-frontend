# UMPL frontend

This React/Vite site deploys to Vercel and calls `https://api.umpluganda.com/api` in production.

## Automatic production deploys

Every push to `master` runs [`.github/workflows/deploy-vercel.yml`](.github/workflows/deploy-vercel.yml). In the GitHub repository, add these **Actions secrets**:

- `VERCEL_TOKEN` — Vercel account token
- `VERCEL_ORG_ID` and `VERCEL_PROJECT_ID` — values generated by `vercel link` (or found in `.vercel/project.json`)
- `VITE_API_URL` — `https://api.umpluganda.com/api`

In Vercel, add `VITE_API_URL=https://api.umpluganda.com/api` for the Production environment too. For local work copy `.env.example` to `.env` if required.

## React + Vite

This template provides a minimal setup to get React working in Vite with HMR and some ESLint rules.

Currently, two official plugins are available:

- [@vitejs/plugin-react](https://github.com/vitejs/vite-plugin-react/blob/main/packages/plugin-react) uses [Oxc](https://oxc.rs)
- [@vitejs/plugin-react-swc](https://github.com/vitejs/vite-plugin-react/blob/main/packages/plugin-react-swc) uses [SWC](https://swc.rs/)

## React Compiler

The React Compiler is not enabled on this template because of its impact on dev & build performances. To add it, see [this documentation](https://react.dev/learn/react-compiler/installation).
